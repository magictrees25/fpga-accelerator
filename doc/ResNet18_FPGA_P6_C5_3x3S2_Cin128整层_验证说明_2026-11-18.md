## 参数与调度

| 项目 | 参数 |
|---|---|
| 代表层 | `layer3.0.conv1` |
| 输入 | 28×28×128，INT8 |
| 卷积 | 3×3，stride=2，padding=1 |
| 输出 | 14×14×256，INT32 |
| 固定硬件 Tile | 4×4×8，M=16、N=8 |
| 每 M 的通道计算 | 两段 K=576，总 K=1152 |
| 空间 Tile 数 | ceil(14/4)×ceil(14/4)=16 |
| 输出通道组数 | 256/8=32 |
| 逻辑 Tile 总数 | 16×32=512 |

按空间 Tile 行、空间 Tile 列、输出通道组遍历：

```text
for ty = 0..3
  for tx = 0..3
    for ng = 0..31
      output_origin = (4*ty,4*tx)
      output_channels = 8*ng .. 8*ng+7
      start -> 服务 32 次 C-Tile 装载 -> done -> 同步读回 128 个值 -> 全局拼接
```

全部 Tile 只复位一次，使用同一份完整输入和权重。每个 M 的 C0、C1 都遍历九个卷积核位置及各自的 64 个输入通道。C0 清累加器，C1 保留部分和，只有 C1 完成后才写回。

本地 BRAM 地址、Host 握手和逐拍 Reader 检查沿用已通过的 P6-C4；不改变 PE、K Controller 或 Reader。每个 M/C 请求仍装载 576 个激活字节和 576 个 64-bit 权重字。

## 两类补零必须分别检查

### 有效输出的卷积 padding

当全局输出 y、x 均在 0～13 内，按标准卷积坐标读取：

```text
input_y = 2*output_y + ky - 1
input_x = 2*output_x + kx - 1
```

只有输入坐标超出 0～27 的 tap 置零，其余 tap 正常参与卷积。完整有效输出范围内，padding 共涉及 83 个空间 tap；乘以 128 个输入通道及 32 个输出通道组，得到 339968 个补零激活装载字节、169984 个补零 FEED 对。

此参数下，最后有效输出坐标 13 读取输入 25～27，因此有效输出只会使用上侧和左侧的图像补零。

### 超出输出范围的空间尾部

最后一行/列 Tile 起点为 12，固定 4×4 Tile 中只有两行/列有效。

| Tile 类别 | 含通道组的数量 | 每 Tile 有效结果 | 每 Tile 物理结果 |
|---|---:|---:|---:|
| 4×4×8 | 288 | 128 | 128 |
| 4×2×8 / 2×4×8 | 192 | 64 | 128 |
| 2×2×8 | 32 | 32 | 128 |
| 合计 | 512 | 50176 | 65536 |

输出坐标 14 或 15 不属于网络输出。TB 将这些 M 的整个 3×3×128 输入窗口置零，仍执行两段计算、写回和同步读回，要求结果为零，随后丢弃，不写入全局输出数组。

**不能仅按输入坐标越界来处理空间尾部。** 例如输出 y=14 的 ky=0 仍对应输入 y=27；仅做图像边界判断可能得到非零的无效输出。本 TB 在输入取值前先检查输出坐标是否有效。

空间尾部共 15360 个物理结果，对应 2211840 个置零激活字节和 1105920 个 FEED 对，与上面的有效输出 padding 分开计数，不重复累计。

Output BRAM mask 仍为 `8'hff`，表示每个物理结果字的八个通道有效；全局空间裁剪由 TB 的拼接逻辑负责。

## Golden Model 与覆盖检查

在发出任何 start 前，TB 以 y、x、n、ky、kx、c 六重循环直接计算完整 14×14×256 卷积参考。使用有符号 INT8 激励及 INT32 结果，不调用 DUT、局部 K、装载或 Tile 地址辅助函数。

Golden 同时独立统计每个有效输出位置应使用的 padding 数量。每 Tile 的预期值取自完整 Golden，空间尾部期望零；用于逐段 PE 检查的另一套参考必须与之相符。

保留并扩展的检查包括：

- 每次装载请求/确认、M/C 元数据、激活与权重写地址、打包、Bank 和写入数量。
- 每段 288 个请求/FEED、13 拍 DRAIN，Reader 响应延迟、局部 K 和全局通道配对。
- 卷积核位置与行切换、C0/C1 之间的流水线清零及全部 64 个 PE 部分和保持。
- 中间段不得写回；每个 M 最终地址写一次、mask 全有效。
- 每 Tile 的 128 个物理结果以及同步 32-bit lane 读回全部比较。
- 从实际读回值拼接全局 HWC 数组，拒绝重复写入与越界；最终逐项核对全部 50176 个值及所属 Tile。
- 无效空间输出必须为零且不得拼接；padding 与空间尾部的装载/FEED 数量分别正确。
- 连续 512 次 start/done、511 次输出通道组切换及旧输出缓存覆盖。
- 单次装载请求/完成等待的 2000 拍上限及 60000000 拍全局 watchdog；未完成不得打印 PASS。

整层周期包含大量 Host 装载，watchdog 已按整层规模放宽。请执行 Run All；首次输出 `INFO: building independent full 14x14x256 convolution Golden` 后，TB 会先计算完整参考，再开始逐 Tile 打印进度。
